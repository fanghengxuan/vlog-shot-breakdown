## 1. 这条片子怎么讲

不是剧情片，是**户外亲子日常蒙太奇**：

```text
玩具飞机开场 → 泡泡 → 举高/拥抱 → 扛肩、揉眼
→ 长椅喝水 → 一起玩飞机 → 秋千击掌 → 高处俯拍收尾
```

标题在片外定主题（父亲节），片内靠动作和音乐完成情绪：

- 前段：吹泡泡、举高、拥抱，情绪上行；
- 中段：扛肩、揉眼、坐长椅喝水，节奏降下来；
- 后段：玩飞机、秋千击掌，再给一个情绪高点；
- 结尾：高处俯拍拉远，人物变小，环境变大，最后淡出。
