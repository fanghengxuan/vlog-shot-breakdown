# 字段定义与示例

逐镜表的 10 个字段。目标是让另一个人拿着表就能复现机位与光线，而不需要再看一遍原片。

---

## 1. 字段说明

| 字段 | 必填 | 说明 | 常见错误 |
|---|---|---|---|
| 镜号 | 是 | 按成片顺序编号 | 把同一镜头内的运镜切成多个镜号 |
| 截图 | 是 | 代表画面；运动镜头可加起幅/落幅 | 用接触表缩略图代替，导致看不清构图 |
| 时间码 | 是 | 镜头开始时间，精确到 0.1s | 编造精度（如 12.37s） |
| 时长(s) | 是 | 结束减开始 | 与时间码不一致 |
| 场景 | 是 | 客厅 / 餐厅 / 卧室 / 窗边 / 户外 | 写“家里”这种无法指导布景的词 |
| 画面内容 | 是 | 谁、在哪、做什么 | 只写“很好看”“很温馨” |
| 机位 / 景别 / 运镜 | 是 | 高度、距离、景别、运动方式 | 把“手持”写成“固定” |
| 光线 / 声音 / 字幕 | 是 | 光向、光源、声音类型、字幕位置 | 把后期旁白写成同期声 |
| 分析 / 复刻要点 | 是 | 这一镜的核心手法与复现方法 | 写成剧情概括 |
| 确定性 | 是 | A / B / C | 全部填 A |

---

## 2. 景别参考

| 景别 | 画面范围 | 常见距离（等效 50mm） |
|---|---|---|
| 大特写 | 眼睛、手、叶脉、杯口 | 0.2–0.4m |
| 特写 | 头部 / 手部 / 单个物体 | 0.3–0.6m |
| 近景 | 胸部以上 | 0.6–1.0m |
| 中景 | 腰部以上 / 半身 | 1.0–1.8m |
| 全景 | 全身 + 环境 | 2.5–4m |
| 远景 | 人物很小，环境为主 | 4m 以上 |

---

## 3. 机位高度参考

| 高度 | 画面感觉 | 适用 |
|---|---|---|
| 20–40cm | 地面视角，代入感强 | 爬行、玩玩具、脚部特写 |
| 60–80cm | 儿童坐姿眼高 | 地毯玩耍、吃饭 |
| 90–110cm | 儿童站姿眼高 / 成人坐姿 | 对话、看鱼缸、窗边 |
| 130–160cm | 站立俯拍 | 桌面、玩具箱、穿衣 |
| 170cm+ | 成人眼高 | 全景、跟拍 |

> 机位高度是推断值，写区间，不要写单点。

---

## 4. 运镜写法

| 写法 | 含义 |
|---|---|
| 固定 | 三脚架 / 支撑，画面不动 |
| 手持 | 有呼吸感，允许轻微晃动 |
| 缓推 | 缓慢靠近主体 |
| 缓拉 | 缓慢远离主体 |
| 横移 | 机身平行于被摄面移动 |
| 跟随 | 跟着人物走 |
| 升降 | 机位上下移动 |
| 俯拍 | 从高处向下拍 |
| 低机位 | 贴近地面向上拍 |

---

## 5. 光线写法

- 顺光：光源在相机后方
- 侧光：光源在主体侧面
- 侧逆光：光源在主体侧后方
- 逆光：光源在主体后方，窗/天空过曝
- 实用光源：台灯、灯牌、屏幕、蜡烛
- 补光：反光板、LED、白墙反射

> 不要写“自然光”就结束；要写光从哪来、打在谁身上、窗是否过曝。

---

## 6. 确定性写法

| 写法 | 含义 |
|---|---|
| `A` | 画面/剪辑点可直接确认 |
| `B` | 机位、运镜、光线为合理推断 |
| `A/B` | 画面 A，拍法 B |
| `B/C` | 拍法不确定，剪辑点也存疑 |
| `C` | 信息不足，只能标推测 |
