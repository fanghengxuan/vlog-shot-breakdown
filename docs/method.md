# 完整方法：从成片到可执行脚本

本文描述一套可重复的拉片流程。目标是**还原拍摄方法**，不是复述剧情，也不是评价人物。

---

## 0. 准备

```bash
# 依赖
ffmpeg / ffprobe
python >= 3.10
pip install -r requirements.txt
```

建议把片源放在 `input/`，输出放在 `out/`，两者都不要提交到 Git。

---

## 1. 读元数据

```bash
ffprobe -v error -show_format -show_streams input.mp4
```

记录：

- 总时长（秒）
- 分辨率与画幅比例
- 帧率（决定时间码精度）
- 视频编码 / 音频编码

示例：

```
Duration: 00:01:41.73
Video: h264, 1080x720, 30 fps
Audio: aac, 44100 Hz, stereo
```

> 1080×720 是 3:2 横屏，不一定是原生画幅，可能是裁切。画幅比例会影响“等效焦段”的判断。

---

## 2. 找镜头边界

### 2.1 场景检测

```bash
ffmpeg -i input.mp4 \
  -vf "select='gt(scene,0.30)',showinfo" \
  -an -f null - 2>&1 \
  | grep showinfo \
  | sed -E 's/.*pts_time:([0-9.]+).*/\1/'
```

得到候选切点（秒）。建议跑两轮：

- `0.30`：只保留明显硬切
- `0.12`：补充弱切，同时会抓到快摇、快速下摇、遮挡造成的误报

### 2.2 人工复核

对每个候选点抽切点前后各 1 帧：

```bash
ffmpeg -ss 12.20 -i input.mp4 -frames:v 1 before.jpg
ffmpeg -ss 12.40 -i input.mp4 -frames:v 1 after.jpg
```

如果两帧是同一机位的连续运动（不是切换），合并为一个镜头。  
如果两帧构图完全不同，确认为切点。

### 2.3 镜头表

最终得到：

| 镜号 | 开始 | 结束 | 时长 |
|---|---|---|---|
| 01 | 0.0 | 1.7 | 1.7 |
| 02 | 1.7 | 3.1 | 1.4 |

> 场景检测的边界误差约 ±0.2 秒。不要编造精度；写“约”或保留一位小数即可。

## 3. 抽帧与接触表

### 3.1 每个镜头的三类帧

- **起幅**：切点后 0.1–0.3 秒
- **中段**：动作或构图最完整的一刻
- **落幅**：下一个切点前 0.1–0.3 秒

静态镜头起落幅差异小，保留一张代表性画面即可。  
运动镜头、长镜头建议保留起幅 / 落幅对照，便于判断推拉摇移。

### 3.2 全片接触表

```bash
ffmpeg -i input.mp4 -vf "fps=1,scale=384:-1,tile=5x5" -frames:v 1 sheet_%02d.jpg
```

按 25 秒一张生成接触表，用来快速看全片节奏。  
接触表只用于扫描，不要用它判断焦段和焦点。

### 3.3 抽帧命令

```bash
ffmpeg -ss 12.30 -i input.mp4 -frames:v 1 -q:v 2 frame_12.jpg
```

`-ss` 放在 `-i` 前是快速定位；如果需要帧精确，放在 `-i` 后并配合 `-accurate_seek`。

## 4. 逐镜分析顺序

建议按“先事实、后推断、再复刻”的顺序填写。

### 4.1 可见事实（A）

- 画面里是谁、在哪、做什么
- 景别：大特写 / 特写 / 近景 / 中景 / 全景
- 构图：主体位置、前景、背景
- 光线方向：顺光、侧光、逆光、侧逆光
- 剪辑点：硬切、叠化、淡入淡出
- 声音：同期声、旁白、音乐、环境声
- 字幕：有无、位置、出现时间

### 4.2 拍摄方法推断（B）

- 机位高度：地面 / 儿童眼高 / 坐姿 / 站立 / 俯拍
- 距离：0.3–0.5m（特写）、0.8–1.5m（中景）、2.5–4m（全景）
- 运镜：固定、推、拉、摇、移、跟、升降
- 焦段：广角 24–35mm、标准 50mm、中长焦 85–135mm（等效）
- 光源：窗光、台灯、灯牌、反光板、补光灯

### 4.3 复刻要点

每个镜头写 1–2 句“怎么拍”：

- 机位怎么摆
- 焦点对哪里
- 曝光对哪里测
- 让被摄者做什么，不做什么
- 需要拍几条 / 录多久

### 4.4 不确定点（C）

单独列出：

- 实际焦段、光圈、ISO、快门
- 是否补光、补光设备
- 镜头外如何引导
- 拍摄顺序、拍摄天数
- 是否后期裁切 / 调色 / 变速

## 5. 输出脚本表

### 5.1 CSV

按 `examples/example-shots.csv` 的字段填写，一行一个镜头。

### 5.2 生成 Excel

```bash
python tools/build_shot_table.py \
  --video input.mp4 \
  --shots shots.csv \
  --out out/breakdown.xlsx
```

生成结果包含：

- 每镜一张截图
- 时间码 / 时长 / 场景 / 画面
- 机位 / 景别 / 运镜
- 光线 / 声音 / 字幕
- 分析 / 复刻要点
- 确定性

### 5.3 版式建议

- A4 横向
- 表头深色，段落行浅色
- 冻结表头
- 打印时重复表头
- 每页 5–7 个镜头，段落尽量从新页开始

## 6. 复刻执行

成片顺序 ≠ 拍摄顺序。按以下原则重排：

1. **先静物 / 空镜**：无人物，光线稳定，适合先拍。
2. **再同期动作**：吃饭、玩耍、穿衣，一次布光拍完。
3. **后引导互动**：牵手、对话、看鱼缸，需要家长配合。
4. **最后固定大景**：三脚架，录 2–3 分钟选段。
5. **补特写**：手部、玩具、植物、照片墙。

每个 setup 记录：镜号、人物、道具、机位、预计时长、优先级。

---

## 7. 局限

- 场景检测无法区分“硬切”和“快速运动”，必须人工复核。
- 成片经过平台转码，通常没有 EXIF；焦段、光圈、ISO 只能推断。
- 旁白与字幕可能经过后期重写，不能当作现场同期声。
- 拍摄顺序、镜头外引导、补光设备无法从成片确认。
- 儿童状态不可控，实际拍摄条数通常远多于成片镜头数。
